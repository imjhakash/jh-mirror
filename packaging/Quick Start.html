JH Mirror · Quick Start

Your phone. One Mac app.

Mirroring, files, media, apps, notifications and clipboard are included.
The Android companion and runtime tools are built into JH Mirror.

1. Install JH Mirror

Open the JH Mirror disk image. Drag JH Mirror to Applications, then open it from Applications. You can eject the disk image afterward.

This build supports Apple silicon and macOS 26 or later. It is locally signed rather than notarized. If macOS blocks the first launch, first attempt to open JH Mirror, then use System Settings → Privacy & Security → Open Anyway for JH Mirror and confirm Open. Allow local network access and notifications when asked.

You do not need Homebrew, Python, Java, the Android SDK or separate JH Mirror downloads to use the app.

2. Pair your Android phone

  1. On the phone, enable Developer options: open About phone → Software information and tap Build number seven times.
  2. For Android 11 or later, connect both devices to the same Wi-Fi. Open Developer options → Wireless debugging and turn it on.
  3. Choose Pair Phone in JH Mirror. On the phone choose Pair device with QR code and scan the Mac's code. Code pairing is also available.

For Android 8–10, use a USB cable, enable USB debugging, approve this Mac on the phone and choose Use USB-connected phone.

JH Mirror installs its bundled phone companion during pairing. Unlock the phone normally if asked. Use Device Check to see which features your phone supports and how to fix a failed check.

3. Open your tools

Click the small white arrow at the mirror's top-right to open Phone Tools. Files, Media Library and the App Library are beside your mirror. Drop Mac files into Phone Files to send them; drag phone files into Finder to save them.

The menu bar opens your phone screen, camera and microphone. The dashboard opens only when you choose Dashboard. Use Help → Setup & Add-ons for setup status and links.

Optional · phone camera in Mac calls

OBS Studio camera component

  1. Download OBS Studio for macOS, Apple silicon from its official site. Move OBS to Applications.
  2. Open OBS, choose Start Virtual Camera and approve the camera extension when macOS asks. Follow the prompt to System Settings; the location varies with macOS. The official setup help below explains the approval.
  3. Stop Virtual Camera and quit OBS. Keep OBS installed.
  4. In JH Mirror → Setup & Add-ons, choose Refresh Status. Open Phone Camera, choose Front or Rear, rotate if needed, then select OBS Virtual Camera in your calling app.

JH Mirror sends video directly to the installed camera component. During normal calls OBS stays closed. Phone camera capture requires Android 12 or later and starts only when you choose it. Closing the camera window stops capture; minimizing keeps it running.

Optional · phone microphone in Mac calls

BlackHole 2ch audio driver

  1. Use the official BlackHole download page or installation guide below. Choose BlackHole 2ch.
  2. Run its installer and complete the macOS administrator approval. Restart the Mac if the installer requests it or the device does not appear.
  3. In JH Mirror → Setup & Add-ons, choose Refresh Status. Turn on Phone Mic in JH Mirror, then select BlackHole 2ch as the microphone in your calling app.

Keep your usual Mac speakers or headphones as the call output. BlackHole runs as an audio driver, so no extra audio window needs to stay open. Phone microphone capture requires Android 11 or later.

OBS and BlackHole are independent, optional projects. Install either only for the call input you need. All other JH Mirror tools work without them, subject to the phone's capabilities.
